# عکس‌های پروفایل بیماران

فایل‌های عکس را با این نام‌ها در این پوشه قرار دهید:

| فایل | بیمار |
|------|--------|
| `patient-1.png` | زهرا احمدی |
| `patient-2.png` | محمد رضایی |
| `patient-3.png` | فاطمه کریمی |
| `patient-4.png` | حسین موسوی |

تا زمانی که عکس اضافه نشده، حروف اول نام (initials) نمایش داده می‌شود.

مسیر در دیتا: `/assets/images/patients/patient-{id}.png`
